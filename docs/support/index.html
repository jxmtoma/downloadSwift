Help and troubleshooting

Support

Detect media

  1. Open the extension on the page containing the video.
  2. Select Enable media detection and approve site access.
  3. Start playing the video, then reopen the extension.
  4. Select a detected item to download it.

If nothing appears

  • Reload the page after enabling detection, then play the video again.
  • Confirm the browser still grants the extension access to that site.
  • Try a direct MP4/WebM file or an unencrypted on-demand HLS stream.
  • Remember that YouTube, DRM, encrypted or live streams, and access-control bypassing are not supported.

Contact support

Email ylrbei.studio@gmail.com with your browser version, operating system, the website domain, and what happened.

Do not send passwords, cookies, authentication tokens, or private media links.
