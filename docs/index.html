Free · Version 0.4.0 · Released August 4, 2026 · See what changed

Free

No account, no subscription, no ads. Every feature is available to everyone.

High speed

Stream segments are fetched concurrently and retried automatically, so long videos finish fast.

Several files at once

Queue every video detected on a page: MP4, WebM, MOV, and M4V files, plus on-demand HLS and DASH saved as MP4.

Every desktop OS

The same extension on macOS, Windows, Linux, and ChromeOS.

On-device

No developer server, analytics, advertising, or tracking.

Background progress

Downloads continue after the source tab closes, show an ETA, and report clear completion status.

Designed for media you may save

YouTube, DRM, encrypted or live streams, paywall bypassing, and access-control bypassing are not supported.

Supported browsers

  • Google Chrome 116 or later — macOS, Windows, Linux, and ChromeOS.
  • Microsoft Edge 116 or later — macOS, Windows, and Linux. Same package as Chrome.
  • Firefox 142 or later — macOS, Windows, and Linux. store listing coming soon
  • Safari 26 or later — macOS only. coming soon

Changelog

0.4.0 — August 4, 2026 latest

  • Download on-demand DASH (.mpd) manifests as MP4, merging separate audio and video tracks into one movie.
  • Add Firefox and macOS Safari packages built from the same source.
  • Support bilibili video pages, whose player exposes no manifest to detect.
  • Show a preview frame for each detected video, at the shape of the video, so an ad or player stub is obvious at a glance.
  • Write downloads as progressive MP4. Fragmented files would not play from disk on macOS.
  • Report a stream's real size instead of the size of the text manifest listing its segments.
  • Ignore video responses too small to be a video, which is what most ad and player-stub MP4s are.
  • Report why a download could not start instead of a generic message.
Earlier releases

0.3.2 — August 4, 2026

  • Show an estimated completion time alongside active download progress.
  • Add Open file and Show in folder actions to completion notifications.
  • Support the same Manifest V3 package in Microsoft Edge.

0.3.1 — August 2, 2026

  • Keep one entry per stream rather than one per tab, so a page that embeds several players no longer shows just one of its videos.
  • Detect video files a player fetches in the background, including URLs that carry no file extension.
  • Stop listing a stream's own segments as separate videos.
  • Send the page's referrer when downloading a stream, as direct downloads already did.

0.3.0 — August 1, 2026

  • Detect media as soon as detection is enabled, instead of only after the background worker restarted.
  • Reload the current tab when detection is enabled, since media a page has already requested cannot be observed afterwards.
  • Stop observing media requests immediately when detection is turned off.
  • Retry a stream segment that fails instead of abandoning the download.
  • Fetch stream segments concurrently, which noticeably shortens long streams.
  • Report stream progress on percentage changes, keeping the popup responsive on streams with many segments.
  • Start direct downloads whose URLs carry long signing tokens.
  • Apply the temporary header rule only to the extension's own requests.

0.2.1 — July 31, 2026

  • Rename the extension to Video & Media Downloader.

0.2.0 — July 29, 2026

  • Introduce a consistent icon, popup palette, and store identity.
  • Restrict detection and downloads to HTTPS media.
  • Follow the browser's UI language in English, Spanish, French, German, Brazilian Portuguese, Japanese, Korean, Simplified Chinese, and Traditional Chinese.
  • Expand the permission disclosure to cover all locally handled data.

0.1.1 — July 28, 2026

  • Finalize HLS MP4 duration metadata so downloaded videos report their real duration and expose a seekable timeline.

0.1.0 — July 28, 2026

  • Detect direct video files and HLS/DASH playlists.
  • Save direct files and supported on-demand HLS streams with local progress, cancellation, MP4 transmuxing, and page-title filenames.
  • Continue downloads after the source tab closes and notify on completion.
  • Separate detected, downloading, and downloaded popup views.
